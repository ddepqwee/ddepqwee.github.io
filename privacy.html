Privacy Policy

Neon Bounce Uploader · Effective date: October 13, 2026

1. About the application

Neon Bounce Uploader ("the application") is a private desktop tool used only by the owner of the Neon Bounce YouTube channel. It uploads videos generated by the owner's own software to the owner's own YouTube channel. It uses YouTube API Services.

2. YouTube and Google policies

By using the application you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Data the application accesses

  • The application requests a single permission: youtube.upload, which allows it to upload videos to the authorized channel.
  • It does not read, collect or store any personal data, channel statistics, comments, contacts, or any information about other YouTube users.
  • The only data it sends to YouTube is the video file and its title, description and tags.

4. Storage

The OAuth access token is stored only on the owner's own computer, in a local file. It is never sent to any server other than Google's. No cookies or analytics are used by the application or by this website.

5. Sharing

No data is sold, shared with or disclosed to any third party.

6. Revoking access

Access can be revoked at any time on the Google security settings page (Third-party apps with account access). Deleting the local token file also removes the application's stored access.

7. Changes

If this policy changes, the updated version will be published on this page with a new effective date.

8. Contact

Questions about this policy can be sent through the Neon Bounce YouTube channel.
